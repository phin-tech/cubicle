# Cubicle

**Cubicle Window Manager**: instant, named, searchable workspaces for macOS.

Cubicle gives every display its own workspaces in place of macOS Spaces. Switching is instant: Cubicle moves the other workspaces' windows just off a corner of the screen and brings the new workspace's windows back, the way AeroSpace and Spaceman do. Every window stays on the one macOS Space, so sending a window to another workspace is instant too. Keep one macOS Space per display (remove the others in Mission Control): Cubicle can't see windows on a Space you aren't on.

Cubicle began as a fork of [InstantSpaceSwitcher](https://github.com/jurplel/InstantSpaceSwitcher) by jurplel (MIT licensed; see `LICENSE`), with its custom Space names from [PR #111](https://github.com/jurplel/InstantSpaceSwitcher/pull/111). It no longer switches macOS Spaces, so none of that switching code remains.

- **Workspace grid** (default Ctrl+Option+Cmd+Space): a grid of the workspaces on the display under your cursor, with arrow-key, number-key and click navigation.
- **Search by name**: type to filter. Matching is fuzzy ("ino" finds "innopts") and ignores the workspace you are already on.
- **Custom names**: press ⌃R in the grid to rename the selected workspace, or use Settings > Workspaces.
- **As many workspaces as you like**: each display starts with 8. ⌃N in the grid or `cubicle new-space` adds one; ⌃⌫ twice in the grid or `cubicle remove-space` removes one, and its windows join the workspace before it.
- **Trackpad swipes**: three- or four-finger swipes left and right switch workspaces (Settings > General).
- **Move a workspace** to the next display with its windows and name: the menu bar, `cubicle move-workspace`, or a shortcut.
- **Send a window** to another workspace from the grid (⇧Return), the ⌃⌥⌘-click window menu, or `cubicle send`.
- **Window snapping**: halves, quarters, Maximize, Full Screen, Center and Restore, Rectangle-style. The shortcuts are Rectangle's (⌃⌥ + arrows, U/I/J/K, ↩, C, ⌫), plus ⌃⌥F for Full Screen, which covers the whole display and hides the menu bar and Dock without leaving the workspace, and are off until you turn them on in Settings > Keyboard Shortcuts. Also in the ⌃⌥⌘-click window menu, `cubicle snap`, and Alfred's `w` keyword. Settings > General has a gap setting.
- **`cubicle` CLI**: `cubicle list [--here] [query]`, `cubicle go <name|number>`, `cubicle send <name|number>`, `cubicle left|right`, `cubicle new-space`, `cubicle remove-space [name|number]`, `cubicle grid`, `cubicle snap <action> [--app <name>|--window <id>|--previous]`, `cubicle windows [--json]`, `cubicle actions`, `cubicle gap [points]`. It talks to the running app over a private local socket, so it needs no Accessibility permission of its own, and it starts Cubicle if it is not running.
- **Alfred workflow** (Settings > General > Add the Workflow to Alfred, or `just alfred-install`): `cb` opens Cubicle's menu. `cb windows` lists every window on every workspace: ↩ goes to one, ⇥ sends it to another workspace or onto a new one you name. It also does go, send, snap, rename, add, remove and move. `cb stashed` lists stashed windows: ↩ opens one, ⇥ unstashes it, moves it to another edge or names its Tab; Open Next and Unstash All are there too. A window's ⇥ menu can stash it, and `cb stack` has the stacking commands (next/previous, swap, pause, resume). `@mail` jumps to a workspace and `w left` snaps the window you were in. The workflow is a thin shim: the menu comes from `cubicle alfred`, so it updates with the app, and the keywords can be changed in Alfred's Configure Workflow sheet. Needs the Alfred Powerpack.
- **Lazy Susan** (Settings > General > Add Cubicle to Lazy Susan, shown when Lazy Susan is installed): adds a Cubicle group under `c`, with go to and send to a workspace (keyed by number), windows, stashed windows, left/right, new and rename workspace, rename Tab, the grid and a snap group. Its live lists come from `cubicle leader <go|send|windows|stashed>`, which print Lazy Susan items as JSON. Add it again after an update to replace the group.

### Install (from source)

Tasks are in the `justfile` (`brew install just`; run `just` to list them).

```sh
just install          # build release, install to /Applications, link ~/.local/bin/cubicle, launch
just alfred-install   # import the Alfred workflow
just dev              # while hacking: test, rebuild, relaunch
```

Grant Accessibility to Cubicle when macOS asks. Builds go through Xcode (`project.yml`, regenerated by `just gen`) and are signed from `Signing.local.xcconfig` (see `Signing.xcconfig`); with a real team the app's identity stays the same across rebuilds, so macOS keeps the grant. If shortcuts stop responding, `just reset-accessibility` clears a stale one. Add `~/.local/bin` to your `PATH` to use the `cubicle` command.

The Debug app is produced at `./build/xcode/Build/Products/Debug/Cubicle.app`.
