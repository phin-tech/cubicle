# Cubicle

**Cubicle Window Manager**: instant, named, searchable Spaces for macOS.

Cubicle is a fork of [InstantSpaceSwitcher](https://github.com/jurplel/InstantSpaceSwitcher) by jurplel (MIT licensed; see `LICENSE`). It builds on the custom Space names from [PR #111](https://github.com/jurplel/InstantSpaceSwitcher/pull/111) and adds a summoned grid with type-to-search.

- **Space grid** (default Ctrl+Option+Cmd+Space): a grid of the Spaces on the display under your cursor, with arrow-key, number-key and click navigation.
- **Search by name**: type to filter. Matching is fuzzy ("ino" finds "innopts") and ignores the Space you are already on.
- **Custom Space names**: Settings > Spaces.
- **Window snapping**: halves, quarters, Maximize, Center and Restore, Rectangle-style. The shortcuts are Rectangle's (⌃⌥ + arrows, U/I/J/K, ↩, C, ⌫) and are off until you turn them on in Settings > Keyboard Shortcuts. Also in the ⌃⌥⌘-click window menu, `cubicle snap`, and Alfred's `w` keyword. Settings > General has a gap setting.
- **`cubicle` CLI**: `cubicle list [--here] [query]`, `cubicle go <name|number>`, `cubicle left|right`, `cubicle grid`, `cubicle snap <action> [--app <name>|--window <id>|--previous]`, `cubicle windows [--json]`, `cubicle actions`, `cubicle gap [points]`. It talks to the running app over a private local socket, so it needs no Accessibility permission of its own, and it starts Cubicle if it is not running.
- **Alfred workflow** (`alfred/`): type `@` plus part of a Space's name, e.g. `@ino`, or `w` plus a window command, e.g. `w left`. Needs the Alfred Powerpack.

### Install (from source)

Tasks are in the `justfile` (`brew install just`; run `just` to list them).

```sh
just install          # build release, install to /Applications, link ~/.local/bin/cubicle, launch
just alfred-install   # import the Alfred workflow
just dev              # while hacking: test, rebuild, relaunch
```

Grant Accessibility to Cubicle when macOS asks. Builds go through Xcode (`project.yml`, regenerated by `just gen`) and are signed from `Signing.local.xcconfig` (see `Signing.xcconfig`); with a real team the app's identity stays the same across rebuilds, so macOS keeps the grant. If shortcuts stop responding, `just reset-accessibility` clears a stale one. Add `~/.local/bin` to your `PATH` to use the `cubicle` command.

The install and build instructions below are inherited from InstantSpaceSwitcher and refer to its releases and Homebrew cask. To run Cubicle, build from source; the Debug app is produced at `./build/xcode/Build/Products/Debug/Cubicle.app`.

# InstantSpaceSwitcher (upstream README)

Native instant workspace switching on macOS. No more waiting for animations.

https://github.com/user-attachments/assets/037422c9-3fb7-41cd-8da7-58d28c4c8eff

## Features

- Does not require disabling SIP
- Uses native macOS spaces
- Custom space names in the switching overlay and Spaces menu
- Free

A CLI is provided (`Cubicle.app/Contents/Helpers/cubicle help`). See the `cubicle` command in the Cubicle section above.

## Custom space names

Open **Settings > Spaces** to name desktops on each display. Names can be up to **512 characters** and are saved automatically. Clear a name to show its number again.

Custom names appear in the switching overlay and Spaces menu. Desktop names in Mission Control stay unchanged.


## Installation

### Homebrew

```sh
brew install --cask jurplel/tap/instant-space-switcher
```

After installation the app is located inside `/Applications/InstantSpaceSwitcher.app`


### Downloads

Pre-built binaries are available through Github Releases [here](https://github.com/jurplel/InstantSpaceSwitcher/tags).

### Build from source

```sh
# Needs Xcode and `brew install xcodegen just`. For Cubicle use `just install` or `just dev` (see above).
git clone https://github.com/jurplel/InstantSpaceSwitcher
cd InstantSpaceSwitcher
just debug && open ./build/xcode/Build/Products/Debug/Cubicle.app
```

### Troubleshooting / First time startup

1. When opening the app the first time you are likely to run into any of the following warnings:

> "Apple could not verify InstantSpaceSwitcher.app is free of malware"

> "App is damaged and can’t be opened"

> "App can't be opened because the developer cannot be verified"

Please follow the instructions [here](https://wiki.hacks.guide/wiki/Open_unsigned_applications_on_macOS_Sequoia_and_newer) for instructions on how to allow the app to run[^1].

2. Afterward you will get a warning that InstantSpaceSwitcher wants to use accessibility features. You have to allow this.

3. Then open the app from the Applications folder and the configuration window should appear.

## Background
When I first bought a high refresh rate monitor, around ~2018, I could tell that the space switching animation was longer because it had scaled with the refresh rate. Because of this, I eventually stopped using spaces altogether, and have been looking for a solution ever since. 

The workaround in this project is to create a synthetic trackpad gesture with an artificially high velocity. This effectively skips the animation.

If you work at Apple, and your team owns the space switching animation, please fix this long-standing bug[^2] (and let us disable the animation natively, please).

[^1]: This happens because the app is not signed, which requires a costly Apple Developer account
[^2]: And I know for a fact there is a rdar for this
