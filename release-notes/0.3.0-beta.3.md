## Smoother workspace switches

Switching workspaces flashes less. Before, windows moved one at a time, so you could see the desktop, or windows
popping in and out, partway through a switch. Now:

- **The new workspace's windows go back first**, front-most first, and Cubicle waits for all of them before it moves
  the old workspace's windows away, so the desktop doesn't show in between.
- **Each app's windows move at the same time as other apps'**, so a slow app only holds up its own windows.
- **Chrome, Electron apps and others stop animating the move.** Cubicle turns off their VoiceOver mode
  (`AXEnhancedUserInterface`) while it moves their windows, then turns it back on.

### Try a cover

`cubicle switch-style` picks what covers a switch, if anything, so you can compare:

- `none`: no cover. This is the default.
- `black`: the display goes black for the switch and fades back in.
- `freeze`: asks macOS to hold off redrawing the screen. Reports say this does nothing on recent macOS. It's here to
  compare.
- `black-freeze`: both.

Run `cubicle switch-style` on its own to see which one is on.
