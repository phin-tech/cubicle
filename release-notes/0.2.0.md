## Send windows to another Space (experimental)

`cubicle send <name|number>` moves the focused window to a Space on its display, found by fuzzy name or number, and
takes you along with it. Cubicle needs Accessibility access for this.

You can pick how the move happens:

- `--via-virtual` moves the window through a temporary virtual "staging" display. Add `--stay` to leave the window on
  the target Space while you stay where you are.
- `--via-display` moves it through another display you already have. `--stay` works here too.
- `--quick-drag` uses a faster version of the default title-bar drag.

The menu bar has a new **Experimental Virtual Display** item. It shows whether the staging display is on and lets you
turn it on or off yourself.

## Staging display settings

By default the staging display turns itself off after 10 seconds without a move. You can change this in **Settings →
General → Window Moves**: set any delay from 1 to 3600 seconds, or switch automatic shutdown off so repeated moves stay
fast. Each finished move starts the countdown again.
