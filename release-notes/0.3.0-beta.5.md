## As many workspaces as you want

### New

- **Add and remove workspaces.** Each display starts with 8 and keeps its own count, with no limit. Add one with ⌃N
  in the workspace grid or `cubicle new-space`. Remove one with ⌃⌫ twice in the grid or `cubicle remove-space
  [name|number]`. Its windows join the workspace before it, and the workspaces after it each move down a number,
  taking their windows, names and bindings along. Only the first 16 have shortcuts of their own.
- **Rename from the grid.** Press ⌃R in the grid to rename the selected workspace in place. Return saves, Escape
  cancels, and an empty name goes back to the number.
- **Full Screen.** A new snap (⌃⌥F, `cubicle snap full-screen`, or the ⌃⌥⌘-click window menu) makes a window
  cover its whole display while it stays on its workspace. The menu bar and Dock auto-hide while a full-screen
  window is showing, and your own settings come back afterwards. Press it again to put the window back. It isn't
  macOS's full screen, so switching stays instant.
- **New workspace from windows.** Press ⌃⌥⌘N, choose **New Workspace from Windows…** in the menu bar, or run
  `cubicle pick-workspace`. Then click the windows you want, press Return and name the workspace. Cubicle moves
  them to an unused workspace and takes you there.

### Fixed

- Quitting Cubicle now always shows every window again. A window left hidden by a crash used to stay off screen
  for good; Cubicle now brings back any window it finds stuck in a corner.
