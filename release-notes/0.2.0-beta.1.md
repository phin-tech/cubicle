## Send windows to another Space without the command line (experimental)

0.1.2 added `cubicle send`. This beta adds three ways to send a window from the keyboard and mouse. Each moves the
window to another Space on its display. When displays have separate Spaces, you stay where you are and the window
goes on its own.

- **⌃⌥⌘-right-click any window** for a menu of the Spaces on its display. Pick one, or press its number. You can turn
  this off in **Settings → General → Window Moves**.
- **In the Space grid**, press ⇧Return or ⇧-click a Space to send the focused window there instead of switching.
- **The "Send window to space…" shortcut** (⌃⌥⌘⇧Space) opens the grid already set up to send the focused window.
  It's off by default; turn it on in **Settings → Keyboard Shortcuts**.

While a window is moving, the on-screen display shows its progress, then where the window went, e.g.
"Terminal → Mail". If the move fails, it shows why. You see this even when the switch OSD is turned off.

This is a beta: these are new and have had little testing across apps and display setups.
